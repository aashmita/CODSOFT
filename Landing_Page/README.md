# Responsive Landing Page

A modern and responsive landing page developed using HTML, CSS, and JavaScript. The project focuses on creating an engaging user experience through clean design, intuitive navigation, responsive layouts, and interactive elements.

## Live Demo

🔗 https://aashmita.github.io/CODSOFT/Landing_Page/

## Features

* Fully Responsive Design
* Modern User Interface
* Interactive Navigation Bar
* Smooth Scrolling Experience
* Mobile-Friendly Layout
* Attractive Hero Section
* Call-to-Action Buttons
* Hover Effects and Animations
* Structured Content Sections
* Cross-Browser Compatibility
