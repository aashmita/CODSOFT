# Advanced Smart Calculator
An advanced calculator built using HTML, CSS, and JavaScript featuring scientific calculations, unit conversion, voice input, multilingual support, calculation history, AI-powered read-aloud functionality, and theme customization.

## Live Demo

🔗 https://aashmita.github.io/CODSOFT/Calculator/

## Features

- Basic Arithmetic Operations
- Scientific Calculator
- Unit Converter
- Light & Dark Theme
- English & Hindi Language Support
- Keyboard Input Support
- Calculation History
- Copy to Clipboard
- Voice Input
- AI Read Aloud Feature
- Responsive Design
- Modern User Interface
